# 完成与待确认提醒

在 DeepSeek Harness 里集中记录任务完成、待确认、失败和停止状态，让你切换工作后更容易回来看结果。

- 打开输入框旁的「任务提醒」，查看未读或按状态筛选，点击「前往会话」回到原会话。
- 站内记录默认开启；系统通知默认关闭，只有主动点「开启系统通知」才会请求通知权限。
- 系统通知默认静音，并在 DSH 前台且获得焦点时抑制。可在面板中开启前台通知。
- 系统通知仅显示会话标题，不暴露回答正文。可标为已读、批量标为已读、清理已读记录。

监听插件启动后的原生实时变化，不回放旧会话产生历史误报。已打开会话的原生事件提供失败、停止和完成原因，统一原生待确认状态提供交互提醒。跨会话只获知运行状态结束、没有明确结束原因时，显示「已结束，请查看结果」，不会推断任务成功。部分宿主未公开完整数据时，只提供可用的状态；不会为监控而打开其他会话历史。断开客户端或关闭应用期间无法发通知。

记录只保存在本地，最多 200 条。支持中英文、深浅主题。无 API Key、无模型调用、无外部推送服务器。

「待确认」仅来自宿主当前仍在等待的原生交互请求。因前置检查拒绝而结束的 `blocked` 轮次属于「已结束」，不会误标为待用户确认。

## 安装

在 DSH 的「插件 → 添加插件」中粘贴：

```text
https://github.com/yxue301603/dsh-task-alerts
```

安装并启用后，按 DSH 提示重新加载。仓库已包含预构建文件，无需自行编译。需要 **DSH 0.2.1-rc.2 或兼容的 0.2.x 版本**。迁移、整套安装与升级说明见[工具箱安装指南](https://github.com/yxue301603/dsh-everyday-plugins/blob/main/docs/INSTALLATION.md)。
