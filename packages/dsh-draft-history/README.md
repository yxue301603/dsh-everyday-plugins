# 草稿历史 · Draft History

给 DeepSeek Harness 输入框多一份后悔药。按会话记录草稿版本，误清空、改坏后可以预览、搜索和恢复。

## 安装与使用

在 DSH「插件 → 添加插件」中填写以下 GitHub 仓库地址（也可使用本地插件目录）；按宿主提示启用及重新加载。需要 DeepSeek Harness **0.2.1-rc.2 或更新的 0.2.x**。它是原生 DSH 插件，无须安装浏览器扩展，不调用模型。

```text
https://github.com/yxue301603/dsh-draft-history
```

整套安装、迁移和升级步骤见[工具箱安装指南](https://github.com/yxue301603/dsh-everyday-plugins/blob/main/docs/INSTALLATION.md)。

输入框旁点击「草稿历史」。输入停止约 0.9 秒时自动记录；在发送、清空或离开会话前尽量保存最后一份文本。也可以点击「保存当前」立即保存。DSH 自带草稿持久化继续正常工作；插件不会在你进入会话时自行覆盖输入框。

- 每个会话独立，历史可按内容搜索，支持复制和单条删除。
- 「插入当前草稿」把历史加入当前光标处，保留原有文字和附件；原光标选区不会被删除。
- 「替换当前文本」需要再次确认，先备份当前文本，通过原生修订号校验替换；含附件、引用、正在发送或文本过长时禁用。
- 暂停自动记录后，已有历史仍可使用；手动保存仍可用。
- 清除本会话历史不会清空输入框；同一份未编辑的文本不会立刻被后台重新记入。

## 数据与边界

仅在当前 DSH 浏览器来源的本地存储保存**纯文本**。不上传、不访问密钥、不记录附件本体，不恢复文件、命令和引用芯片的语义关系；引用在历史里只是其可复制的文字。恢复不会自动发送消息。已发送的输入也可能保留为编辑历史，恢复前请自行确认。

默认最多 40 个会话，每会话 12 个版本；仅展示最近 30 天记录，新保存时清理超龄记录。每条最多 48,000 个字符，总量最多约 800,000 个字符；达到上限时优先保留较近访问会话的版本，过长草稿不自动截断。页面强制崩溃前最后不到 0.9 秒的编辑可能来不及保存。不同 DSH 来源、机器和浏览器之间不自动同步。

读取损坏记录或写入失败时显示错误，不静默覆盖损坏的原记录。建议先复制重要文本再处理浏览器存储。清除 DSH 站点数据也会移除插件历史。界面支持中文、英文与深浅主题，所有输入只走 DSH 官方接口。
