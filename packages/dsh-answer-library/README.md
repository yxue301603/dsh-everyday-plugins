# 回答收藏与摘录

为 DeepSeek Harness 添加一个本地个人资料库：收藏好用的回答、命令和片段，再次需要时快速找到并插入草稿。

## 日常使用

- 点击回答下方的 `☆` 收藏全文；先选中此回答中的文字再点 `☆`，只收藏所选内容。
- 从输入框旁的「回答收藏」打开资料库，也可展开「从当前会话收藏」选择已加载的回答。
- 按内容、标题、标签搜索，编辑标题和摘录，使用逗号添加多个标签。
- 复制内容，或安全插入当前草稿。插件不会自动发送，也不会覆盖打开面板后变化的草稿。
- 「原会话」返回收藏的来源会话；删除收藏前需要在面板内确认。

收藏保存在当前浏览器或桌面客户端的本地存储，不会同步到其他设备。最多 1,000 条，单条最多 200,000 个字符，总量受浏览器存储限制。清理应用数据会清除收藏。没有 API Key、模型调用或联网传输。

支持中文、英文以及 DSH 深色和浅色主题。仅使用原生回答事件和回答动作扩展点，不扫描页面文字。选文来自当前回答时会校验它确实包含在原回答内。

独立安装包和安装说明见主仓库发布页。需要 DeepSeek Harness `0.2.1-rc.2` 或兼容版本。
